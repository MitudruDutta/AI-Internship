# AI Internship — Applied ML Projects

A collection of weekly AI/ML internship projects, each driven by a real client
brief. Work is organised by week, building from data handling to deployed demos.

## Projects

### 🍎 FreshHarvest — Freshness Inspection (Weeks 1–2)

**FreshHarvest Logistics**, a cold-storage warehousing company, ships fruit whose
freshness is checked manually — inconsistent (lighting, fatigue) and costly. The
goal: a deep-learning model that classifies fruit images as **fresh** or
**spoiled** in real time on a conveyor belt, plus a demo app.

### 🩺 MediAssist AI — Healthcare Q&A (Week 3 →)

**MediInsight Health Solutions** wants evidence-based summaries on **intermittent
fasting** for obesity / Type 2 Diabetes / metabolic disorders. The goal: a RAG
(retrieval-augmented generation) Q&A system over peer-reviewed literature. Week 3
builds the **PubMed → ChromaDB ingestion pipeline** that feeds it.

## What each week did

| Week | Project | Focus | Outcome |
|---|---|---|---|
| **[Week 1](Week%201/README.md)** | FreshHarvest | Load, deduplicate, augment, split, visualize; train a **CNN from scratch** (plain → regularized + tuned) | Clears the 90 % target on val/test |
| **[Week 2](Week%202/README.md)** | FreshHarvest | **Transfer learning** with **ResNet50**; serve via **FastAPI** + a **Streamlit** drag-and-drop demo | ~99.9 % test accuracy, interactive demo |
| **[Week 3](Week%203/README.md)** | MediAssist | **PubMed → ChromaDB** ingestion pipeline (search PMIDs, fetch articles, embed + store for semantic retrieval) | 300 IF articles ingested + searchable |

## Quick start

```bash
# environment
python -m venv .venv && source .venv/bin/activate
```

**FreshHarvest demo (Week 2):**

```bash
pip install -r "Week 2/fastapi_backend/requirements.txt"
pip install -r "Week 2/streamlit_app/requirements.txt"
# place dataset at dataset/FRUIT-16K/, then train + run (see Week 2 README)
jupyter nbconvert --to notebook --execute --inplace "Week 2/FreshHarvest_Week2.ipynb"
cp "Week 2/resnet50_freshharvest.pth" "Week 2/fastapi_backend/"
cd "Week 2/fastapi_backend" && uvicorn main:app --port 8000      # backend
cd "Week 2/streamlit_app"   && streamlit run app.py              # frontend
```

**MediAssist ingestion (Week 3):**

```bash
pip install -r "Week 3/requirements.txt"
cd "Week 3" && python ingest.py            # PubMed -> ChromaDB (300 articles)
```
